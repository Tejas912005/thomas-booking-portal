# Portal Demo Screenshots & Capture Guide

To produce the portfolio presentation or interview demo artifacts, capture the following 10 views from the running application:

---

### Recommended Screenshots:

1. **`01_home_sentence_search.png`**
   - **View**: Home page (`/`)
   - **Details**: Shows the oversized Fraunces serif typographic sentence search with the inline editable destination and date fields, subtle paper grain, and manifesto columns.

2. **`02_results_editorial_list.png`**
   - **View**: Search Results (`/hotels?location=Mumbai`)
   - **Details**: Shows the horizontal editorial list with hotel names in serif, city small caps, amenities list, and prices in monospace on the right.

3. **`03_hotel_row_hover_reveal.png`**
   - **View**: Search Results list row on hover
   - **Details**: Shows the interactive hover state expanding the descriptive narrative and magnifying the abstract architectural visual identity.

4. **`04_hotel_detail_asymmetric.png`**
   - **View**: Property Detail Page (`/hotels/1`)
   - **Details**: Displays the 60/40 asymmetric layout: left column story and amenities, right column sticky booking ticket with live quote.

5. **`05_custom_date_range_picker.png`**
   - **View**: Calendar popover on detail or home page
   - **Details**: Displays the custom inline calendar with disabled past dates, sand range highlighting, and the live "N nights" badge.

6. **`06_nearest_dates_suggestions.png`**
   - **View**: Hotel Detail page when fully booked
   - **Details**: Demonstrates the alternative dates engine: the notice and selectable "ticket stubs" proposing 3 alternative available stay windows within $\pm 14$ days.

7. **`07_booking_folio_form.png`**
   - **View**: Reservation Form (`/book?hotelId=1...`)
   - **Details**: Displays the guest intake form, live quote summary ticket, and editorial typography.

8. **`08_confirmation_boarding_pass.png`**
   - **View**: Confirmation Page (`/confirmation?reference=HB-XXXXXX...`)
   - **Details**: Full-width digital boarding pass with perforated cutout edges, large reference code in monospace, guest details, and copy/print buttons.

9. **`09_manage_booking_and_cancel.png`**
   - **View**: Guest Portal (`/manage`)
   - **Details**: Retrieval by reference and email, followed by the minimal confirmation modal dialog for cancelling.

10. **`10_dark_mode_edition.png`**
    - **View**: Any page with theme toggled to dark mode
    - **Details**: Showcases the warm charcoal background (`#171512`), preserved terracotta accent (`#E8633B`), and high-contrast typography.
